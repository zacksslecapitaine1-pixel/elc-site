# ELC — English Language Center

Site web de l'**English Language Center** (Lomé, Togo), centre de formation linguistique : cours d'anglais pour tous niveaux, programme EI3MONTHS et préparation au TOEFL iBT.

**Démo :** https://zacksslecapitaine1-pixel.github.io/elc-site/

## Pages

Accueil · Qui sommes-nous · Nos cours · EI3MONTHS · Expressions · Contact

## Stack technique

HTML · CSS · JavaScript
